Курсы для тех, кто уже пишет код и хочет понять, как всё устроено внутри

Каждый курс ведёт один проект от первого запуска до прода. Объяснения сверены с исходниками и документацией, цифры сняты с живого кластера. Код и тексты открыты под лицензией MIT.

Курсы

  1. 01 Flink в проде Apache Flink 2.2 для Java-разработчика, который работал со Spark. За 21 урок ты собираешь PayGuard, антифрод для потока платежей, и доводишь его до Kubernetes, мониторинга и разбора аварий. 21 урок · Java 17 · Kafka · Flink SQL · Kubernetes →

Как устроены курсы

Один проект насквозь
Каждый урок продолжает предыдущий. Снапшот проекта после урока лежит в репозитории, отставший проект можно заменить им и идти дальше.
Сверено с исходниками
Утверждение об устройстве фреймворка опирается на строки кода в теге релиза и на раздел документации, ссылки стоят рядом с текстом.
Теория, практика, задание
В уроке есть симуляторы, которые можно покрутить, команды для терминала, задача на проект, ответ для сверки и глоссарий.
Один файл
Курс собирается в одну HTML-страницу. Её можно сохранить и читать без сети, прогресс хранится в браузере.
