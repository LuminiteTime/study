Задание. Почини свой старый конфиг

В корне проекта лежит flink-conf.yaml, с которым твой кластер получал ноль TaskManager. Перепиши его так, чтобы Flink 2.2.1 реально применил настройки. Сам исходный файл и Makefile оставь как есть, новый файл положи в conf/config.yaml внутри проекта.

  1. Создай файл с правильным именем и ключами Flink 2.x. Сохрани смысл настроек, это 4 слота, параллелизм 2, состояние в куче и каталоги чекпоинтов в /tmp.
  2. Подними JobManager и TaskManager обычным docker run в отдельной сети, смонтировав файл в /opt/flink/conf/config.yaml. Образ бери flink:2.2.1-java17.
  3. Докажи, что настройки применились, запросами к REST.

Готово, если /overview показывает 1 TaskManager и 4 слота, а /jobmanager/config содержит твои значения.

Подсказка. Родной config.yaml в образе задаёт не только адрес JobManager. Посмотри на него командой docker run --rm flink:2.2.1-java17 cat /opt/flink/conf/config.yaml и подумай, на каком адресе процессы слушают сеть, если ключей bind-host нет.
