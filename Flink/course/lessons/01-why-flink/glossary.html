Глоссарий урока

Apache Flink
Движок для обработки потоков данных с состоянием. Программа на нём работает непрерывно и переживает падения без потери результатов.
Micro-batch
Режим Spark Structured Streaming, при котором записи копятся и обрабатываются небольшими пакетными задачами.
Задание (job)
Программа Flink, отправленная на кластер. В потоковом режиме работает, пока её не остановят.
Оператор (operator)
Один шаг обработки в задании, например источник, фильтр или окно.
Подзадача (subtask)
Один параллельный экземпляр оператора. При параллелизме 4 у оператора четыре подзадачи.
JobManager
Процесс, который управляет заданиями, раздаёт работу и координирует снимки. Подробно в уроке 2.
TaskManager
Рабочий процесс, в котором выполняются подзадачи. Похож на экзекутор Spark.
Слот (task slot)
Единица ресурсов TaskManager, в которой выполняются подзадачи. Их число задаёт ключ taskmanager.numberOfTaskSlots.
Состояние (state)
Данные, которые оператор хранит между записями, например счётчик платежей карты.
Сетевой буфер (network buffer)
Участок памяти, куда складываются записи перед отправкой другому TaskManager. Уходит заполненным или по таймауту.
Apache Kafka
Распределённый журнал сообщений. Записи лежат в топиках и хранятся заданное время, поэтому читать их можно повторно.
Топик (topic)
Именованный журнал в Kafka, разбитый на партиции.
Партиция (partition)
Часть топика Kafka с собственным порядком записей. Единица параллельного чтения.
Коннектор (connector)
Библиотека, связывающая Flink с внешней системой. Выходит отдельно от Flink и собирается под его конкретную версию.
Толстый jar (fat jar)
Один файл с твоим кодом и всеми его зависимостями. Его собирает плагин Shadow для Gradle.
REST-интерфейс
HTTP-интерфейс JobManager на порту 8081. Через него работает Web UI, и им же удобно пользоваться из скриптов.
Web UI
Панель Flink в браузере. Показывает граф задания, метрики, чекпоинты и ошибки.
Docker Compose
Инструмент, который поднимает несколько контейнеров по описанию из одного YAML-файла.
Record
Вид неизменяемого класса в Java. Компилятор сам создаёт конструктор, геттеры, equals и hashCode.
