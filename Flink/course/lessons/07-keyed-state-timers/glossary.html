Глоссарий урока

Состояние с ключом (keyed state)
Состояние оператора после keyBy, разложенное по ключам. Функция видит только значение текущего ключа, Flink переключает ключ перед каждой записью и каждым таймером.
ValueState
Вид состояния с одним значением на ключ. Методы value() и update().
MapState
Вид состояния со словарём на ключ. Удобен, когда у ключа много независимых частей, например корзины времени.
ListState
Вид состояния со списком на ключ. Подходит, когда нужны сами элементы, и опасен, когда список растёт без ограничения.
ReducingState и AggregatingState
Виды состояния с одним свёрнутым значением на ключ. Каждое add сразу объединяется с накопленным через ReduceFunction или AggregateFunction.
Дескриптор состояния (state descriptor)
Описание состояния с именем и типом значения. По имени Flink находит состояние при восстановлении, на дескрипторе включается TTL.
KeyedProcessFunction
Функция нижнего уровня DataStream API для потока после keyBy. Метод processElement вызывается на каждую запись, onTimer при срабатывании таймера.
Таймер (timer)
Отложенный вызов onTimer для ключа на заданный момент по времени события или обработки. На один ключ и момент существует не больше одного таймера, таймеры входят в снимок.
Слияние таймеров (timer coalescing)
Округление времени таймеров, чтобы много событий одного ключа делили один таймер. Уменьшает число таймеров и размер снимка.
TTL (time-to-live)
Срок жизни значения состояния. Задаётся через StateTtlConfig на дескрипторе и во Flink 2.2 считается только по времени обработки.
Время обработки (processing time)
Показания часов машины, на которой работает оператор. Противоположность времени события.
Watermark
Отметка в потоке, которая утверждает, что событий раньше этого времени больше не будет. Один на подзадачу, двигает таймеры всех её ключей.
Бэкенд состояния (state backend)
Хранилище, в котором живёт состояние операторов. Выбирается ключом state.backend.type.
HashMapStateBackend
Бэкенд по умолчанию. Хранит состояние Java-объектами в куче TaskManager, быстрый и ограниченный памятью.
RocksDB
Встраиваемое хранилище ключ-значение на диске. Во Flink служит бэкендом для состояния больше памяти, каждое обращение сериализует ключ и значение.
Группа ключей (key group)
Единица раскладки состояния по подзадачам. Их число равно максимальному параллелизму, при смене параллелизма группы переезжают целиком.
Namespace состояния
Второй уровень адресации состояния внутри ключа. В окнах это окно, в KeyedProcessFunction пустой VoidNamespace.
Кардинальность ключей
Число разных значений ключа, которое увидит оператор за время жизни состояния. Главный множитель размера состояния.
Корзина (bucket)
Отрезок времени фиксированной длины, по которому копится сумма. Вместо всех событий хранится одно число на отрезок.
Дедупликация
Удаление повторов одной и той же записи. В PayGuard делается по paymentId с памятью на час.
Test harness
Тестовая обвязка Flink, которая запускает один оператор без кластера и даёт управлять watermark, временем и состоянием. ProcessFunctionTestHarnesses создаёт её для функций.
mapGroupsWithState
Операция Spark Structured Streaming для произвольного состояния по группе. Один объект состояния и один тайм-аут на группу, вызов раз в micro-batch.
Apache Kafka
Распределённый журнал сообщений. Отсюда читаются платежи и сюда пишутся алерты.
Redis
Хранилище ключ-значение в памяти, к которому обращаются по сети. Частый выбор для внешних счётчиков в обычных сервисах.
