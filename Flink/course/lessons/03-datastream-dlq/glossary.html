Глоссарий урока

DataStream
Основной API Flink для потоковых программ на Java. Объект описывает поток записей одного типа и план его обработки.
Преобразование (transformation)
Шаг в плане задания, например map или process. Из таких шагов Flink позже строит граф.
ProcessFunction
Самая гибкая пользовательская функция DataStream API. Получает запись и контекст, через контекст умеет писать в побочные выходы.
Побочный выход (side output)
Дополнительный выход оператора со своим типом. Запись попадает туда по метке OutputTag.
OutputTag
Типизированная именованная метка побочного выхода. Создаётся как анонимный подкласс, чтобы Flink узнал параметр типа.
DLQ (dead letter queue)
Топик или очередь для записей, которые не удалось обработать. Хранит их для разбора и повторной отправки.
Ядовитая запись (poison pill)
Запись, на которой обработка падает при каждой попытке и из-за которой задание после перезапуска снова возвращается к той же ошибке.
Стратегия перезапуска (restart strategy)
Правило, по которому Flink перезапускает упавшее задание. Без чекпоинтов по умолчанию равна none, с чекпоинтами exponential-delay.
Чекпоинт (checkpoint)
Периодический согласованный снимок задания, включая смещения Kafka. После сбоя задание продолжает с него. Подробно в уроке 11.
Savepoint
Снимок задания, который запускают вручную для обновлений и переноса. Подробно в уроке 13.
Смещение (offset)
Порядковый номер записи в партиции Kafka. По нему потребитель знает, откуда читать дальше.
TypeInformation
Описание типа данных во Flink. Определяется на клиенте при описании плана и создаёт сериализатор.
Сериализатор (TypeSerializer)
Объект, который переводит записи в байты и обратно и умеет копировать их.
POJO
Обычный Java-класс, который Flink разбирает по полям. Требования это публичный класс, конструктор без аргументов и доступные поля. Record также подходит, если он публичный.
Record
Вид неизменяемого класса в Java. Во Flink считается POJO и создаётся через канонический конструктор.
Generic-тип
Тип, который Flink не смог разобрать по полям. Описывается через GenericTypeInfo и сериализуется через Kryo.
Kryo
Универсальная библиотека сериализации для Java, запасной путь Flink для нераспознанных типов.
Encoder
Механизм Spark, который описывает перевод объектов Dataset во внутренний формат. Ближайший аналог TypeInformation.
Jackson
Популярная Java-библиотека для JSON. Главный класс ObjectMapper превращает текст в объекты и обратно.
Tombstone
Сообщение Kafka с ключом и пустым значением. В топиках с компактированием означает удаление ключа.
Harness (тестовый стенд)
Обёртка из тестовых артефактов Flink. Запускает один оператор в JVM теста и даёт доступ к его выходам.
Цепочка операторов (operator chain)
Несколько операторов, работающих в одном потоке и в одной подзадаче. Записи передаются между ними вызовом метода.
At least once
Гарантия доставки, при которой запись не теряется, но при сбое может прийти повторно. Для приёмника Kafka требует чекпоинтов.
Exactly once
Гарантия, при которой каждая запись влияет на результат один раз. Разбирается в уроке 12.
Обратное давление (backpressure)
Ситуация, когда следующий оператор не успевает и сдерживает предыдущий. Подробно в уроке 4.
