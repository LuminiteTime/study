Глоссарий урока

Динамическая таблица (dynamic table)
Таблица, содержимое которой меняется во времени. Определена над потоком и внутри не материализована.
Непрерывный запрос (continuous query)
Запрос над динамической таблицей, который не завершается и обновляет результат по мере прихода данных.
Changelog (поток изменений)
Поток строк, каждая из которых описывает изменение таблицы и несёт пометку вида изменения.
RowKind
Перечисление Flink с видами изменений строки +I, -U, +U, -D.
ChangelogMode
Класс, в котором коннектор перечисляет виды строк, которые он выдаёт или принимает.
Append-only
Поток изменений только со вставками +I. Строки результата никогда не меняются.
Retract
Режим, в котором обновление занимает две записи, отмену старого значения -U и новое значение +U.
Upsert
Режим, в котором обновление занимает одну запись +U. Приёмник находит строку по уникальному ключу.
Идемпотентность
Свойство операции, при котором её повтор не меняет результат. Запись по первичному ключу идемпотентна.
TVF (table-valued function)
Функция, которая принимает и возвращает таблицу. TUMBLE, HOP, CUMULATE и SESSION добавляют к строкам границы окна.
Водяной знак (watermark)
Отметка в потоке, которая сообщает, что записей старше этого времени больше не ожидается. Закрывает окна. Подробно в уроке 5.
Планировщик (planner)
Компонент Flink, который превращает текст SQL в граф операторов и оптимизирует его.
Apache Calcite
Библиотека разбора и оптимизации SQL. На ней основан планировщик Flink.
Catalyst
Оптимизатор запросов Spark SQL.
Spark SQL и Structured Streaming
Модуль SQL в Apache Spark и его потоковый режим, который описывает поток как растущую таблицу.
Local и Global aggregate
Две фазы агрегации. Локальная считает частичные суммы до обмена по сети, глобальная объединяет их по ключу.
Mini-batch
Режим, в котором агрегация копит пачку записей и обращается к состоянию один раз на ключ. Экономит состояние ценой задержки.
Managed memory
Область памяти TaskManager вне кучи, которой распоряжается сам Flink. Подробно в уроке 19.
TTL состояния
Срок хранения ключа без обновлений. В SQL задаётся настройкой table.exec.state.ttl, значение 0 отключает очистку.
RocksDB
Встраиваемое хранилище ключ-значение на диске. Один из бэкендов состояния Flink.
SQL Client
Консольный клиент Flink, который выполняет SQL интерактивно или из файла.
Lookup join
Соединение, в котором каждая запись потока запрашивает значение из внешней системы в момент обработки.
Window Top-N
Запрос с ROW_NUMBER, который выдаёт N лучших строк на окно один раз, когда окно закрылось.
JDBC-коннектор
Коннектор Flink для реляционных баз через стандартный драйвер Java. Умеет читать, искать по ключу и писать.
PostgreSQL
Реляционная база данных. В проекте хранит справочник продавцов и итоги.
OpenLineage
Открытый стандарт и библиотека для отслеживания происхождения данных. Нужна JDBC-коннектору 4.x при запуске.
SQL-jar (толстый коннектор)
Jar со всеми зависимостями коннектора, включая перепакованную в другой пакет библиотеку Kafka.
Родительский загрузчик (parent-first)
Порядок загрузки, при котором класс сначала ищется в lib/ кластера. Для org.apache.flink. действует всегда.
ServiceLoader
Механизм Java, который находит реализации интерфейса по файлам META-INF/services.
Профиль Compose
Метка службы в Docker Compose. Служба с профилем стартует, только если этот профиль включён.
DDL
Часть SQL, которая описывает объекты, например CREATE TABLE. Во Flink в DDL указаны коннектор, формат и водяной знак.
Атрибут времени
Колонка, которую Flink считает временем записи. Бывает временем события с водяным знаком или временем обработки через PROCTIME().
Calc
Вершина плана, которая выполняет проекцию и фильтр без состояния.
ConstraintEnforcer
Оператор перед приёмником, который проверяет ограничения колонок, например NOT NULL. Его добавляет сборка приёмника.
DLQ (dead letter queue)
Отдельный топик для записей, которые не удалось обработать. В проекте это payments.dlq из урока 3.
