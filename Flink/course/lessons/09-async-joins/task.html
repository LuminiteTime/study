Задание. Платёж без подтверждения

Interval join выдаёт только пары. Платёж, который банк так и не подтвердил, в payments.confirmed не появится, и никто об этом не узнает. Для антифрода такой платёж подозрителен. Напиши правило, которое выдаёт алерт, если подтверждение не пришло за пять минут по времени события.

  1. Создай pipeline/UnconfirmedPaymentFunction на основе KeyedCoProcessFunction<String, PaymentEvent, PaymentConfirmation, FraudAlert>. Ключ это paymentId, срок ожидания передаётся в конструктор в миллисекундах.
  2. Алерт строй через FraudAlert.of с идентификатором правила unconfirmed.
  3. Подтверждение может прийти раньше платежа. Это нормальный случай, алерта быть не должно.
  4. После того как судьба платежа решена, состояние и таймеры по этому ключу должны быть очищены.
  5. Подключи правило в PayGuardJob с именем и uid rule-unconfirmed. Срок возьми из PaymentConfirmationJoin.MAX_DELAY. Алерты правила должны пройти через обогащение вместе с остальными.
  6. Напиши UnconfirmedPaymentFunctionTest на harness с двумя входами.

Готово, если выполнены все условия.

  1. Тесты проверяют четыре случая. Подтверждения нет, и алерт выдан. Подтверждение пришло вовремя, алерта нет и таймеров не осталось. Подтверждение пришло раньше платежа, алерта нет. Watermark сдвинулся только на одном входе, алерта ещё нет.
  2. ./gradlew test проходит.
  3. В графе на стенде появилась вершина rule-unconfirmed, и её вход равен входу join-confirmations.

Подсказка первая. Harness для такой функции создаёт ProcessFunctionTestHarnesses.forKeyedCoProcessFunction. Ему нужны функция, два селектора ключа и тип ключа.

Подсказка вторая. Watermark оператора с двумя входами равен минимуму по входам, это ты видел в уроке 8. В тесте двигай watermark каждого входа отдельно. На стенде помни, что топик подтверждений с --confirm 0 замолчит, и watermark этого входа пойдёт вперёд только через минуту по idleness.

Подсказка третья. Чтобы удалить таймер, нужно знать точное время, на которое он поставлен. Подумай, из какого состояния его можно вычислить.
