Глоссарий урока

Время события (event time)
Момент, когда событие случилось, записанный в самой записи. У платежа это поле eventTimeMs. Результат по нему воспроизводим при любом повторном прогоне.
Время обработки (processing time)
Показания часов машины, на которой оператор видит запись. Ждать ничего не нужно, но результат зависит от скорости и перезапусков.
Watermark
Служебный элемент потока с меткой T. Обещает операторам, что событий с меткой T и раньше больше не будет, и двигает их время события.
Допуск беспорядка (out-of-orderness)
Насколько запись может отстать от самой свежей. В forBoundedOutOfOrderness watermark равен максимуму меток минус допуск минус 1 мс.
Позднее событие (late event)
Запись, чья метка времени не больше текущего watermark оператора. Watermark сам её не удаляет, решение принимает оператор, например окно.
Метка времени (timestamp)
Число миллисекунд, привязанное к записи во Flink. У записи Kafka есть своя метка, по умолчанию её ставит продюсер в момент отправки.
TimestampAssigner
Функция стратегии watermark, которая достаёт метку времени из записи. Получает запись и метку, пришедшую от источника.
Генератор watermark (WatermarkGenerator)
Объект, который видит метки записей и периодически выпускает watermark. Источник создаёт по генератору на каждый сплит.
Стратегия watermark (WatermarkStrategy)
Описание того, как задание понимает время. Создаёт TimestampAssigner и генератор watermark, передаётся в fromSource.
Простой (idleness)
Состояние входа, по которому дольше таймаута нет записей. Простаивающий вход не участвует в минимуме watermark. Включается через withIdleness.
Сплит (split)
Кусок работы источника, который читает одна подзадача. У источника Kafka один сплит равен одной партиции топика.
Схема десериализации (DeserializationSchema)
Класс, превращающий байты записи источника в объект Java. Работает внутри источника, до того как запись получит метку времени.
StatusWatermarkValve
Клапан на входе задачи. Помнит watermark каждого входного канала и пропускает дальше минимум, только когда он вырос.
Партиция (partition)
Часть топика Kafka со своим порядком записей. Единица параллельного чтения и, во Flink, единица подсчёта watermark в источнике.
Apache Kafka
Распределённый журнал сообщений. Записи лежат в топиках, разбитых на партиции, у каждой записи есть метка времени.
withWatermark в Spark
Способ задать watermark в Spark Structured Streaming. Берёт наибольшее время события по всему запросу минус порог и применяет его с начала следующего micro-batch.
Счётчик (Counter)
Метрика Flink, которая только растёт. В пробе считает поздние события.
Гистограмма (Histogram)
Метрика Flink, которая хранит распределение значений. В REST видна как набор чисел с суффиксами _min, _max, _p99 и другими.
Тестовый стенд (harness)
Обёртка из тестового jar Flink, которая запускает один оператор в JVM теста и позволяет подавать ему записи и watermark.
REST-интерфейс
HTTP-интерфейс JobManager на порту 8081. Ресурс /jobs/.../vertices/.../watermarks отдаёт watermark подзадач вершины.
Web UI
Панель Flink в браузере. Показывает Low Watermark на вершинах графа и вкладку Watermarks по подзадачам.
Окно (window)
Оператор, который собирает записи за отрезок времени и выдаёт результат, когда watermark проходит конец отрезка. Тема урока 6.
