Задание. Скрипт состояния кластера

Когда заданий и TaskManager становится больше, смотреть в браузер неудобно. Напиши scripts/cluster-status.sh, который одной командой показывает то, что мы сегодня проверяли руками. Пользуйся только curl и jq, CLI Flink не нужен.

  1. Первая строка показывает число TaskManager, сколько слотов занято из общего числа и версию Flink.
  2. Для каждого задания со статусом RUNNING скрипт показывает его имя, статус и идентификатор.
  3. Под каждым заданием идут его вершины, у каждой параллелизм, статус и имя.
  4. Адрес кластера по умолчанию http://localhost:8081, переменная окружения FLINK_REST его заменяет.
  5. При ошибке в команде скрипт завершается, как и submit.sh.

Готово, если при работающем задании вывод показывает одну вершину с параллелизмом 2 и два занятых слота, а после flink cancel остаётся только первая строка с нулём занятых слотов.

Подсказки. Адреса нужны такие, /overview, /jobs и /jobs/<id>. Занятые слоты придётся вычислить из двух полей. В имени поля с дефисом jq требует запись в скобках. Для вставки значений в строку в jq есть интерполяция \(...), а флаг -r убирает кавычки вокруг результата. Посмотри ответ /jobs глазами, прежде чем писать фильтр, названия полей статуса в разных адресах отличаются.
