Ответ

Строка с execution.runtime-mode делает запрос конечным, он читает один снимок таблицы и завершается. Значение tableau у sql-client.execution.result-mode печатает результат таблицей в терминале.

Каталог приходится объявлять заново, потому что клиент запускается новым процессом с новой сессией. Сами данные и описание таблицы лежат в warehouse, и создавать таблицу второй раз не нужно. Сортировка по alerts разрешена именно в пакетном режиме. В потоковом основной порядок обязан идти по атрибуту времени.

docker compose --profile sql exec -T sql-jobmanager sql-client.sh -f /sql/paimon_report.sql

Как проверить, что отчёт согласован с источником. Запусти его дважды с паузой в пару интервалов чекпоинта, числа должны только расти. Чтобы увидеть старую версию, добавь к таблице подсказку /*+ OPTIONS('scan.snapshot-id' = '1') */. Запрос прочитает самый первый снимок и вернёт меньшие числа, если он ещё не удалён сроком хранения.
