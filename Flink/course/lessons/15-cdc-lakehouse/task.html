Задание. Пакетный отчёт по таблице озера

Пока задание payguard-alerts-lake пишет алерты, напиши файл sql/paimon_report.sql. Он должен посчитать, сколько алертов дало каждое правило для каждого уровня риска продавца, и показать результат в терминале.

  1. Запрос читает таблицу fraud_alerts из каталога Paimon.
  2. В результате три колонки, правило, уровень риска и число алертов. Сверху самые частые сочетания.
  3. Файл запускается той же командой sql-client.sh -f, что и остальные, на SQL-кластере.

Готово, если команда завершается сама и печатает таблицу прямо в терминал. В Web UI на порту 8082 пакетное задание завершается, а payguard-alerts-lake продолжает работать. При повторном запуске через минуту числа растут.

Подсказки. Посмотри, какая настройка переводит клиент в пакетный режим и какая отвечает за вид результата в терминале. Подумай, что клиент помнит о каталоге после завершения предыдущего запуска. В потоковом режиме ORDER BY по произвольной колонке не работает, и документация объясняет почему.
