Задание. Дедупликация должна пережить рестарт

В задании PayGuard повтор платежа отсекает DeduplicateFunction. Если она забудет увиденные платежи при рестарте, после каждого падения повторы пройдут дальше и правила посчитают их как новые платежи. Напиши тест, который это проверяет.

  1. Создай src/test/java/dev/study/payguard/pipeline/DeduplicateRestoreTest.java.
  2. Подай платёж в первый экземпляр оператора и сними снимок.
  3. Подними второй экземпляр из снимка и подай в него тот же платёж и ещё один новый.
  4. Проверь выход второго экземпляра.

Готово, если выполнены все условия.

  • Команда ./gradlew test --tests '*DeduplicateRestoreTest' зелёная.
  • В отчёте ./gradlew test стало 45 тестов.
  • Тест падает, если заменить в DeduplicateFunction состояние обычным полем с набором строк. Верни код после проверки.
  • Тест нельзя обмануть функцией, которая отбрасывает вообще все платежи.

Подсказки. Образец лежит в CardProfileRestoreTest. Посмотри, по какому полю функция ключуется в PayGuardJob, селектор ключа в тесте должен быть таким же. В Payments есть готовый paymentOnCard. Последнее условие подсказывает, зачем в третьем пункте нужен новый платёж.
