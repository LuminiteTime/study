Глоссарий урока

Окно (window)
Ограниченный отрезок потока для одного ключа, по которому считается результат. Во Flink это часть keyed state с собственными таймерами.
Tumbling окно
Окна одной длины, которые идут встык и не пересекаются. Каждая запись попадает ровно в одно окно.
Sliding окно
Окна длины size, новое начинается каждые slide. Окна пересекаются, и запись попадает в size / slide окон.
Сессионное окно (session window)
Окно без заранее известных границ. Закрывается, когда между записями ключа проходит пауза дольше заданной.
Global окно
Одно окно на ключ на всё время работы. По умолчанию не срабатывает никогда, требует своего trigger.
Assigner (WindowAssigner)
Часть оконного оператора, которая по времени записи решает, в какие окна она попадает.
Trigger
Часть оконного оператора, которая решает, когда выдать результат окна и очистить ли его содержимое.
Evictor
Необязательная часть оконного оператора, которая убирает записи из окна до или после вызова функции. Отключает предварительное сложение.
AggregateFunction
Функция окна, которая складывает записи в аккумулятор по одной. В состоянии хранит только аккумулятор.
Аккумулятор (accumulator)
Промежуточный итог AggregateFunction, например счётчик и сумма. Хранится в состоянии вместо самих записей.
ProcessWindowFunction
Функция окна, которая получает все записи окна разом и контекст с его границами. Без AggregateFunction хранит все записи окна.
ReduceFunction
Функция, которая сворачивает две записи одного типа в одну. Как и AggregateFunction, считает по мере прихода записей.
allowedLateness
Сколько времени окно живёт в состоянии после срабатывания, принимая опоздавшие записи. По умолчанию ноль.
Позднее срабатывание (late firing)
Повторная выдача итога окна, вызванная опоздавшей записью в пределах allowedLateness. Содержит полный обновлённый итог.
Побочный выход (side output)
Дополнительный выход оператора, помеченный тегом OutputTag. У окна туда уходят записи, которые не приняло ни одно окно.
Watermark
Отметка в потоке, которая утверждает, что событий старше этого времени больше не ждём. Двигает время событий в операторах.
Время события (event time)
Момент, когда событие случилось у источника, например время платежа. Противопоставляется времени обработки на сервере.
Таймер (timer)
Отложенный вызов оператора для конкретного ключа и окна. Таймер по времени события срабатывает, когда его догоняет watermark.
Namespace состояния
Второй уровень адресации keyed state после ключа. Оконный оператор использует окно как namespace, поэтому у ключа может быть много окон сразу.
keyBy и keyed state
keyBy раскладывает поток по ключу, после чего каждый ключ получает своё состояние в одной подзадаче.
MiniCluster
Полноценный Flink внутри JVM теста. Позволяет проверить кусок конвейера с таймерами и состоянием без Docker.
Upsert
Запись по ключу, которая заменяет прежнее значение, если оно есть, и добавляет новое, если нет.
Apache Kafka
Распределённый журнал сообщений. Наше задание читает платежи из Kafka и пишет туда итоги окон.
Spark Structured Streaming
Потоковый движок Apache Spark. Окна задаёт функциями window и session_window, а порог опоздания через withWatermark.
