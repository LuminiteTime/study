Глоссарий урока

Broadcast state
Состояние оператора, копия которого есть в каждой его подзадаче. Пишется только со стороны широковещательного потока, читается при обработке остальных записей. Устроено как словарь и живёт в куче JVM.
Широковещательный поток (BroadcastStream)
Поток, каждая запись которого доставляется во все подзадачи следующего оператора. Получается вызовом broadcast с дескрипторами состояния.
Разбиение BROADCAST
Способ раздачи записей, при котором каждая запись копируется во все каналы к следующему оператору. Его ставит BroadcastPartitioner.
KeyedBroadcastProcessFunction
Функция для потока с ключом, соединённого с широковещательным. processElement обрабатывает записи с ключом и читает broadcast state, processBroadcastElement обрабатывает правила и пишет в него.
Дескриптор состояния (MapStateDescriptor)
Описание состояния, имя и типы ключа и значения. По нему оператор находит состояние, поэтому один и тот же дескриптор передают в broadcast и в функцию.
Оператор с двумя входами (two-input operator)
Оператор, который читает два потока, например после connect. Его watermark равен минимуму watermark двух входов.
Watermark
Служебный элемент потока с меткой T. Обещает, что событий с меткой T и раньше больше не будет, и двигает время события операторов.
Long.MIN_VALUE и Long.MAX_VALUE
Наименьшее и наибольшее значения типа long в Java. Первое означает, что watermark ещё не было, второе обещает, что старых данных от входа не будет никогда.
Простой входа (idleness)
Признак входа, по которому дольше таймаута нет записей. Простаивающий вход не участвует в минимуме watermark. Включается через withIdleness.
Детерминированный код
Код, который при одинаковом входе всегда даёт одинаковый результат. Не читает часы, случайные числа и внешние системы.
Состояние с ключом (keyed state)
Состояние, привязанное к ключу записи, у нас к карте. Каждая подзадача хранит только свои ключи. Тема урока 7.
Таймер (timer)
Отложенный вызов onTimer для ключа. Таймер по времени события срабатывает, когда watermark оператора дошёл до его метки.
Чекпоинт (checkpoint)
Согласованный снимок состояния всего задания, из которого оно восстанавливается после падения. Подробно в уроке 11.
Сериализация Java (Serializable)
Встроенный в Java способ превратить объект в байты. Через неё функции задания уезжают с клиента на TaskManager, поэтому всё, на что ссылаются их поля, должно её поддерживать.
Схема десериализации (DeserializationSchema)
Класс, превращающий байты записи источника в объект Java. Если он вернул null, источник Kafka пропускает запись.
Jackson
Библиотека Java для JSON. ObjectMapper из неё читает JSON в объекты и умеет создавать record через его конструктор.
Консольные клиенты Kafka
Скрипты kafka-console-producer.sh и kafka-console-consumer.sh из поставки Kafka. Первый отправляет каждую строку ввода сообщением, второй печатает сообщения топика.
Партиция (partition)
Часть топика Kafka со своим порядком записей. Порядок между разными партициями Kafka не гарантирует.
Test harness
Обёртка из тестовых jar Flink, которая запускает один оператор в JVM теста. Записи, правила и watermark подаются вручную. Функцию по сети не отправляет.
Broadcast variable в Spark
Значение, которое драйвер Spark один раз рассылает на экзекуторы для чтения. Поменять его можно только созданием новой переменной.
Подзадача (subtask)
Один параллельный экземпляр оператора. При параллелизме 2 у rules-dynamic две подзадачи, и у каждой своя копия правил.
REST-интерфейс
HTTP-интерфейс JobManager на порту 8081. Ресурс /jobs/.../vertices/.../watermarks отдаёт метрику currentInputWatermark подзадач вершины.
