Задание. Блокировка стран

В RuleConfig уже есть поле blockedCountries, но DynamicRules его не читает. Допиши правило, которое срабатывает на платежи из заблокированных стран.

  1. Если страна платежа есть в списке blockedCountries текущих настроек, функция выдаёт алерт. Идентификатор правила blocked-country, объяви его константой рядом с VELOCITY_RULE. В поле detail напиши, какая страна заблокирована.
  2. Алерт выдаётся на каждый такой платёж, без ограничения «раз в минуту», как у velocity.
  3. Сообщение без поля blockedCountries не должно ронять задание.
  4. Добавь в DynamicRulesTest тест. Пришли правило с одной страной и проверь, что первый же платёж из неё даёт ровно один алерт с идентификатором blocked-country:<paymentId>.

Готово, если ./gradlew test проходит, а на стенде после правила с ["PL"] в fraud.alerts появляются алерты blocked-country, примерно на каждый пятый платёж.

Подсказки. Заготовка paymentOnCard из testing/Payments создаёт платёж из страны DE. Подумай, что Jackson положит в поле record, если в JSON такого поля нет. Помни, что настройки в processElement только читаются, менять список нельзя.
